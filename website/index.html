How it works

Get started in three simple steps.

1

Initialize

Run daisy init to set up your project with tasks, prompts, and MCP configuration.

2

Plan

Define tasks manually or run daisy plan to generate them from a PRD using AI.

3

Execute

Run daisy run 10 to execute 10 iterations. Claude Code works through tasks, you watch progress.

Frequently asked questions

Everything you need to know about Daisy.

The Ralph Wiggum Loop is a technique pioneered by Geoffrey Huntley for running Claude Code in continuous autonomous loops. It uses a simple prompt file that tells the AI to pick up tasks, complete them, and signal when done - enabling hands-off development overnight or while you focus on other work.

Yes! Daisy is designed to be non-intrusive. It adds an MCP server that Claude Code can use for task management, but it doesn't modify your existing setup. Your prompts, tools, and configurations remain unchanged.

Daisy gives you full control: set iteration limits, monitor token usage in real-time, and stop execution anytime. The terminal UI shows cost per iteration so you always know exactly what you're spending.

Yes! The daisy plan command supports multiple AI providers including OpenRouter, OpenAI, and Anthropic. Use the provider that works best for your use case.

MCP (Model Context Protocol) is Anthropic's standard for extending Claude's capabilities with custom tools. Daisy runs as an MCP server, providing Claude Code with native tools to manage tasks, track progress, and signal completion - all within the AI's context.

Daisy runs within Claude Code's existing sandbox and respects all your permission settings. It doesn't bypass any security controls - it just orchestrates the loop. Your code stays local and secure.
